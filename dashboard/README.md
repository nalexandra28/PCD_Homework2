# Static dashboard

Single HTML page: it loads `config.js` (see below), opens a **WebSocket** to the project gateway `/ws` path, and renders `stats.snapshot` fields (`popularMovies`, `recentActions`, `connectedClients`). If the socket drops, the client reconnects with exponential backoff and jitter (capped at 60 seconds).

**Hosting**: serve the `dashboard/` folder with any static HTTP server.

## Configuration

`window.__DASHBOARD_CONFIG__` must be set before `app.js` runs. **Generate `config.js` with the infra script** after the WebSocket gateway is deployed to Cloud Run:

```bash
cd infra/scripts
chmod +x 33-write-dashboard-config.sh
./33-write-dashboard-config.sh
```


| Field in `config.js` | Source                                                               |
| -------------------- | -------------------------------------------------------------------- |
| `wsUrl`              | From GCP Cloud Run (via `gcloud` as above).                          |
| `token`              | `WS_GATEWAY_DEMO_TOKEN` in `.env` (must match the deployed gateway). |


## Run the dashboard

1. Deploy `ws-gateway` with `infra/scripts/32-cloud-run-ws-gateway.sh` (at least once).
2. From `infra/scripts`, run `33-write-dashboard-config.sh` so `config.js` points at the live service.
3. Serve the folder, e.g. `cd dashboard && python -m http.server 3000`, and open the printed URL in a browser.

## Files


| File         | Role                                                                                                  |
| ------------ | ----------------------------------------------------------------------------------------------------- |
| `index.html` | Markup: status, counts, popular and recent blocks.                                                    |
| `styles.css` | Layout and theme.                                                                                     |
| `app.js`     | WebSocket client, backoff, JSON handling, DOM updates.                                                |
| `config.js`  | Generated by `infra/scripts/33-write-dashboard-config.sh` (or edited by hand for local-only gateway). |
